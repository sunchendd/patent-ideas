# 02 核心点挖掘：时间轴复用为什么成立、防什么

## 一、问题的形状：层 × 步二维矩阵里的空位

把解码过程摆成矩阵——每行一层，每列一个解码步，每格一次「全量扫描」：

```
              步 t-1        步 t         步 t+1
  第 1 层    [全量扫描]    [全量扫描]    [全量扫描]
  第 2 层    [全量扫描]    [全量扫描]    [全量扫描]
   ...
  第 61 层   [全量扫描]    [全量扫描]    [全量扫描]
```

- **层轴（竖着借）**：IndexCache/IndexShare 删层复用邻层选择；MLI 层间流水把扫描藏进注意力执行时间。已被占。
- **时间轴（横着借）**：同层相邻步，query 只挪一个 token 的隐状态增量，上一步分数大部分有效。**空位，本发明占这里。**

两轴正交：层轴方案保留下的索引器，其每步全量扫描正好由本发明替换。

## 二、数学内核（可证明性是本方案的护城河）

**单头（讲人话版）**：score_j = ⟨q, k_j⟩。相邻步分数变化 = ⟨q_t − q_{t−1}, k_j⟩（分配律），柯西–施瓦茨：

```
|变化| ≤ ‖k_j‖ × ‖q_t − q_{t−1}‖
         ↑固定，缓存     ↑每步算 1 次，全体键共享
```

**多头加权 ReLU（生产形态）**：score_j = Σ_h w_h·ReLU(⟨q_{t,h}, k_{j,h}⟩)。ReLU 1-Lipschitz + 柯西–施瓦茨：

```
|Δscore_j| ≤ Σ_h |w_h|·‖k_{j,h}‖·‖Δq_h‖ ≤ c_j · δ_t
c_j = Σ_h |w_h|·‖k_{j,h}‖  （随键固定，缓存于槽 A）
δ_t = max_h ‖q_{t,h} − q_{t−1,h}‖  （每步一次；保守界，逐头范数可得更紧求和界）
```

**三分类**：真实门槛（真实分数第 k 大）必然落在 [L,U]，L/U = 所有区间左端/右端的第 k 大值：

- s_j − Δ_j ≥ U → 必留（真实分数再低也在门槛上）
- s_j + Δ_j < L → 必出（真实分数再高也够不到门槛）
- 区间跨 [L,U] → 待定，唯一需要读键+点分的集合

**防漏机制**：被跳过期间 Δ_j 每步累加 c_j·δ_t，区间只会展宽；设 Δ_max 超限强制重估——任何键不可能被永远跳过，输出收敛于全量重扫。

**收敛口径**：闭合界=严格一致（无损）；松弛界（δ_t×γ 或收紧 L/U）=误差 ≤ε 有界。

## 三、核心创新点分层（对应权利要求布局）

| 层级 | 创新点 | 必要性 | 防什么 |
|------|--------|--------|--------|
| K1 | 跨步分数缓存 + 漂移界三分类 + 增量 top-k | **独权必要特征** | 防 DSA 族宽泛措辞、防 Quest「统计缓存」 |
| K2 | 多头加权 ReLU 界的构造（c_j、δ_t） | 从权 | 防多头实现绕行 |
| K3 | 小根堆阈值维护 + 收尾精算 + Δ_max 强制重估 | 从权 | 防集合维护的正确性质疑 |
| K4 | 带状读单 kernel 融合 + 双槽逐出 | 从权 | 防纯软件缓存实现绕行 |
| K5 | 与层间复用/流水的叠加组合 | 从权（组合） | 防叠加部署规避 |

## 四、与最近工作的对位

| 方案 | 维度 | 复用什么 | 每步还全量扫吗 |
|------|------|----------|----------------|
| DSA 原始实现 | — | — | 是（问题本身） |
| IndexCache / IndexShare | 层轴 | 邻层 top-k 选择 | 保留层仍然全量扫 |
| MLI（NeurIPS'26 WS） | 层轴 | 邻层选择+流水重叠 | 扫描段仍在，只是被藏起来 |
| Quest / SparQ | 统计缓存 | 页级 min-max 统计 | 每步仍全量评估统计量 |
| LazyLLM（CN118982030A） | 逐步重估 | 无（每步重算注意力图） | 是 |
| **本方案** | **时间轴** | **上一步逐键精确分数 + 漂移界** | **仅新增键 + 待定键（预估 ≤8%）** |

## 五、效果预估与口径警告

口径：7B~671B 稀疏注意力模型、32K~128K 上下文、单卡（H800 级）。预估：64K 读键字节 −91%、每步重打分键 ≤8%、吞吐 ≈2.0×、P99 时延 −33%。

**以上均为选题阶段基于机制的预估值，不是实验结果**。正式申请前必须实测回填，并补多头紧式界与 Δ_max 标定。附图（diagrams/）中全部数字为机制示意（N=10、k=3、δ=0.5 走例），用于讲清计算过程。
