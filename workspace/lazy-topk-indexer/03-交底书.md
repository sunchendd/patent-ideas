## 1　相关技术背景以及最接近的现有技术

### 1.1　背景技术

长上下文场景下，注意力计算量与访存量随序列长度线性增长，成为大模型解码吞吐的主要瓶颈。以 DeepSeek 稀疏注意力（DSA）为代表的生产级方案在每个注意力层前部署轻量索引器（Lightning Indexer）：对当前查询与缓存中全部历史键逐一计算粗略相关性分数（多头加权和的 ReLU 内积形式，无归一化），选出分数最高的 k 个（生产配置 k=2048），本层精确注意力仅对这 k 个键计算。

该技术路线已成为产业主流：DeepSeek-V3.2 及 V4 系列、GLM-5 系列等均采用学习型稀疏注意力；NVIDIA TensorRT-LLM 已于 2026 年 11 月将包含稀疏执行与图重放的完整路径并入主干。自回归解码时，查询向量随生成 token 逐个变化，索引器每个解码步、每层都要对全量历史键重读重打分，键读取量为 O(L)。

### 1.2　与本发明相关的现有技术一

#### 1.2.1　现有技术一的技术方案

DSA 原始实现（DeepSeek-V3.2-Exp 及后续生产部署）：每个解码步对全量历史键重算索引分数并全量排序取 top-k；上一步算好的逐键分数因查询变化而整体作废，只能全部重算。

#### 1.2.2　现有技术一的缺点

（1）索引器每步键读取量随上下文长度线性增长，64K~1M 上下文下全缓存读占满 HBM 带宽——最新研究（Multi-layer Indexer，arXiv:2611.03768）明确指出长上下文下解码瓶颈在索引器扫描而非稀疏注意力本身；（2）索引计算与访存随层数×步数二维放大；（3）上一步分数信息完全弃用，未利用相邻步查询漂移很小这一结构性质。

### 1.3　与本发明相关的现有技术二

层轴优化路线：（a）IndexCache（GLM-5.2 以 IndexShare 发布）按保留率删除部分层的索引器、复用邻层选择结果；（b）MLI（NeurIPS 2026 LCFM Workshop，arXiv:2611.03768）将索引扫描与注意力做层间流水重叠以隐藏扫描延迟。

共同局限：二者只削减层间重复，保留下的每个索引器在每个解码步内仍是全量重扫；「时间轴」（同一层相邻解码步之间）的分数复用在现有技术中未被利用。

## 2　本发明技术方案的详细阐述（发明内容）

### 2.1　本发明所要解决的技术问题

在带学习型稀疏注意力的推理系统中，消除索引器每个解码步对全量历史键的重读与重打分：在不改变模型权重、不重训练、不依赖层间结构的前提下，使每步索引计算从「全量读+全量算」降为「新增键+少量边界键」的带状访问，且选出的 top-k 集合与全量重扫严格一致（闭合界实施例）或误差有界（松弛界实施例）。

### 2.2　本发明的主要发明点概述

核心构思：利用相邻解码步查询漂移的有界性，为每个缓存键维护「最近精确分数 s_j + 固定范数项 c_j + 累计漂移上界 Δ_j」的片上分数缓存；由 Lipschitz 界将每键当前真实分数约束在区间 [s_j−Δ_j, s_j+Δ_j] 内；再由全部区间导出门槛必然范围 [L,U]（L、U 为所有区间左端、右端的第 k 大值），把键三分类：必留（区间整体不低于 U）、必出（区间整体低于 L）、待定（区间跨 [L,U]，唯一需要重算的集合）；经小根堆增量维护 top-k。

四个相互配合的技术手段：① 双槽分数缓存（数据结构层）；② 漂移界三分类判据（判据层）；③ 待定键重估与增量 top-k 合并（算法层）；④ 带状读单 kernel 融合（算子层）。

### 2.3　本发明技术的具体实现方案

#### 2.3.1　本发明应用的系统架构或场景

应用于带学习型稀疏注意力的 LLM 推理服务端（自建集群 / MaaS / 官方 API 后端），部署于 vLLM / SGLang / TensorRT-LLM / MindIE 等推理引擎中，作为索引器算子的替换实现；对 GPU 与 NPU（昇腾）均适用，分数缓存驻留片上 SRAM/缓存。长上下文（≥32K）负载收益最大：智能体多轮长会话、长文档分析、代码工程等场景。

（图 1：现有做法与优化后流程的逐步对比，见 diagrams/fig1_flow.png）

#### 2.3.2　本发明的核心装置/组件/软件逻辑单元

- **模块 1（分数缓存）**：按（层，头组，键序号）索引的双槽记录；槽 A 持久保存最近精确分数 s_j 与范数项 c_j，槽 B 保存累计漂移上界 Δ_j 与最后精算步编号；容量不足按 Δ 降序逐出。
- **模块 2（分类器）**：每步计算一次查询漂移 δ_t；在缓存上生成必留/必出/待定三分类位图，仅做加减与比较，不读键、不算点积。
- **模块 3（增量 top-k 引擎）**：对待定键执行重打分（读键+真实点积），结果写回槽 A 并清零 Δ_j；小根堆增量合并维护 top-k 与阈值；输出前仅对入选 k 个键按当前查询重算修正排序。
- **模块 4（带状读 kernel）**：把每步全缓存线性读改写为 top-k 邻域+边界候选的带状读；分类、重估、堆更新、写回融合为单个 kernel 发射。

#### 2.3.3　发明方案实施例一（本发明最优选的实施例）

##### 2.3.3.1　发明方案实施例一的技术方案

闭合界实施例，每解码步执行：

1. 计算 δ_t = max_h‖q_{t,h}−q_{t−1,h}‖（查询向量由本步前向自然产生）；
2. 对新增 token 的键打 1 次分写入缓存；
3. 分类：s_j−Δ_j ≥ U 判必留，s_j+Δ_j < L 判必出，其余待定；
4. 仅对待定键读键并精算点积，写回缓存、Δ_j 清零；
5. 小根堆增量合并更新 top-k 与阈值 τ_t；
6. 输出前对入选 k 键重算修正排序，交给精确注意力。

被跳过键的 Δ_j 每步累加 c_j·δ_t，区间展宽，设上限 Δ_max 超限强制进入待定集。

**判据的数学基础**——单头形式：score_j = ⟨q, k_j⟩，相邻步变化 = ⟨q_t−q_{t−1}, k_j⟩，由柯西–施瓦茨不等式 |变化| ≤ ‖k_j‖·‖q_t−q_{t−1}‖，右端两项均可不访问键数据获得。多头加权 ReLU 形式（生产形态）：score_j = Σ_h w_h·ReLU(⟨q_{t,h}, k_{j,h}⟩)，利用 ReLU 的 1-Lipschitz 性与柯西–施瓦茨不等式得 |Δscore_j| ≤ Σ_h |w_h|·‖k_{j,h}‖·‖q_{t,h}−q_{t−1,h}‖ ≤ c_j·δ_t，其中 c_j = Σ_h |w_h|·‖k_{j,h}‖ 随键固定缓存于槽 A，δ_t 每步计算一次（保守界；逐头保留范数可得更紧的求和界，属从属设计）。

**正确性**：真实门槛（真实分数第 k 大值）必然落于 [L,U]；判「必留」的键无论真实分数如何都高于门槛、判「必出」的都低于门槛，故输出与全量重扫逐键一致；跳过仅依据数学保证，非近似。

（图 2：核心判定示意，见 diagrams/fig2_axis.png）

**走例**：缓存 10 键，s = (9.0,8.2,7.1,6.5,5.0,4.2,2.0,1.1,0.6,0.4)，Δ = (0.3,0.4,0.3,0.2,0.2,0.5,0.3,0.2,0.4,0.1)。得 L=6.8、U=7.4：键 1、2 必留；键 4~10 必出；仅键 3 待定重算得 7.2。本步点积 1 次+新增键 1 次，对比全量 10 次；结果与全量重扫完全一致。

##### 2.3.3.2　发明方案实施例一区别于现有技术的改进之处以及对应的有益效果

区别于现有技术一（DSA 原始实现）：把每步 O(L) 全量读+全量算替换为 O(新增+待定) 的带状访问，且输出严格一致；区别于现有技术二（IndexCache/MLI）：本发明作用于时间轴而非层轴，可与层轴方案叠加部署。

有益效果（口径：7B~671B 稀疏注意力模型、32K~128K 上下文、单卡；均为选题阶段预估值，待实测回填）：索引器每步 HBM 读键字节在 64K 上下文下下降约 91%；每步重打分键占比 ≤8%；top-k 与全量重扫一致率闭合界下 100%；端到端解码吞吐提升约 2.0 倍；P99 单 token 时延约 −33%；不改权重、零重训练开销。

#### 2.3.4　本发明实施例二（可选实施例）

##### 2.3.4.1　发明方案实施例二的技术方案

（1）松弛界变体：将 δ_t 乘安全系数 γ>1（放全区间）或将 L/U 按系数收紧，进一步压缩待定集规模，输出误差不超过预设 ε（ε 证书可随输出给出）；适合带宽极度紧张的部署形态。（2）页粒度变体：分数缓存按页/块组织，页内取范数上界，以极小缓存容量换取更大粒度的跳过；与逐键粒度可混合部署。（3）其他从属变体：top-k 改为 top-p 或阈值截断（门槛范围构造相应改为分位数区间）；打分函数变化时（无 ReLU、加偏置、门控）凡满足对查询 Lipschitz 的形式均可套用，界按具体形式重推。

##### 2.3.4.2　发明方案实施例二区别于现有技术的改进之处

区别在于以可控误差 ε 换取更大的跳过率与更小的缓存占用；页粒度变体以粒度换容量。二者均不改变「跨步分数缓存+漂移界分类」的必要特征，属同一发明构思下的优选变形。

### 2.4　关键技术点概括及关键点对应的有益效果

- **K1（核心）**：跨解码步分数缓存与漂移界三分类判据——必要技术特征为「维护最近精确分数与漂移上界的缓存 + 由区间与门槛必然范围判定必留/必出/待定 + 仅对待定键重估」。效果：读键量与点积次数由 O(L) 降为 O(新增+待定)。
- **K2**：多头加权 ReLU 打分形式的漂移界构造（c_j 与 δ_t 的定义及推导）。效果：适配生产级索引器，界可离线标定。
- **K3**：增量 top-k 维护（小根堆阈值、收尾精算、Δ_max 强制重估）。效果：集合维护开销与待定规模成比例，且有防漏保证。
- **K4**：带状读单 kernel 融合与双槽缓存逐出策略。效果：访存地址连续、中间结果不落地，NPU/GPU 均可高效实现。
- **K5**：与层间复用/流水的叠加组合。效果：层轴×时间轴正交组合，已有层轴部署可平滑引入。

## 3　发散思维

（1）自适应 k：按待定占比/带宽压力动态调 k 或切换闭合/松弛界；（2）跨层共享分数缓存：相邻层 c_j 高度相关，可共享范数项进一步省容量（与层轴方案正交）；（3）预填充期批量建缓存与 Δ 预热策略；（4）批解码多序列的束状 kernel 组织；（5）把漂移界思想推广到其它「逐 query 评分+选 top-k」结构（如检索头、路由器、MoE 专家选择）；（6）硬件协同：分数缓存驻 NPU 片上 SRAM 的容量规划与逐出指令设计。
